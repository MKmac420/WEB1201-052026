Featured Projects

Song catalogue project

This is a web based group assignment project that uses pure HTML, CSS, and JavaScript with no external frameworks or libraries used. I was mainly responsible for coordinating the effort, creating the mobile hamburger menu, and creating the song grid catalogue. This project demonstrates my ability to use native web languages to create a grid based song catalogue with dynamic updates and the ability to play songs as they pop out.

Java based blackjack program

This is a Java based group assignment that replicates the casino game Blackjack using object-oriented principles. I was responsible for creating the driver class. This program demonstrates strong OOP aligned principles and card deck accuracy where each card is its own object in a deck, allowing for real world blackjack strategies such as card counting to be possible.

McDonalds Supply Chain Database System

This is an Oracle SQL based group assignment that simulated a hypothetical database for a McDonalds supply chain. I was responsible for planning the Entity-Relationship Diagram, which visualizes the relationship between different entities in the database as well as the properties that concern the database.
